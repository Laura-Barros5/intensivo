DESIGN RESPONSIVO

Uma interface feita para qualquer tela

Este projeto demonstra como uma página web pode se adaptar a computadores, tablets e celulares utilizando HTML e CSS.

RESPONSIVIDADE

Um layout que se adapta

Diferentes dispositivos

O layout utiliza media queries para adaptar os elementos de acordo com o tamanho da tela.

Unidades relativas

São utilizadas unidades como rem, em e porcentagem para tornar o layout mais flexível.

Menu responsivo

Em telas menores, o menu de navegação se transforma em um menu hambúrguer.

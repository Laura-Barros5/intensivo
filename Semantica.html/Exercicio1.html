Exercício 2

Layout utilizando apenas <div>

<div class="cabecalho">Cabeçalho</div>
<div class="menu">Menu</div>
<div class="conteudo">Conteúdo</div>
<div class="rodape">Rodapé</div>

Mesmo layout utilizando HTML Semântico

<header>Cabeçalho</header>
<nav>Menu</nav>
<main>Conteúdo</main>
<footer>Rodapé</footer>

Os elementos semânticos deixam o código mais organizado, facilitam a leitura e melhoram a acessibilidade.

Exercício 4

Como aprender HTML

Introdução

HTML é a linguagem responsável pela estrutura das páginas da web. Com ela é possível organizar textos, imagens, tabelas, links e outros elementos.

Desenvolvimento

As tags semânticas tornam o código mais organizado e facilitam a manutenção do projeto, além de melhorar a acessibilidade.

Conclusão

Praticar exercícios é uma das melhores formas de aprender HTML e desenvolver páginas mais bem estruturadas.
